## Сообщение об уязвимостях

**НЕ ПУБЛИКУЙТЕ уязвимости открыто!**

### Контакты

```
GitHub Issues: https://github.com/ZonGRG/anonumosbrowseir/issues/new?template=security_report.md
GitHub Security: https://github.com/ZonGRG/anonumosbrowseir/security/advisories/new
```

### Что указывать в отчёте

1. **Описание** — что именно уязвимо
2. **Шаги для воспроизведения** — как воспроизвести проблему
3. **Ожидаемое поведение** — что должно происходить
4. **Фактическое поведение** — что происходит на самом деле
5. **Версия** — affected version
6. **Влияние** — насколько серьёзна проблема

### Пример отчёта

```
Subject: [SECURITY] Утечка DNS через WebRTC

Description: При использовании WebRTC DNS-запросы
проходят мимо прокси, раскрывая реальный IP.

Steps to reproduce:
1. Включить Tor/прокси
2. Открыть https://browserleaks.com/webrtc
3. Наблюдать реальный IP

Severity: Critical
Affected: 2.0.0 - 2.1.3
Fixed: 2.1.4
```

## Типы уязвимостей

### Critical (критические)

- Remote Code Execution (RCE)
- Утечка паролей или куки
- Обход шифрования
- Привилегии суперпользователя

**Награда:** $500 - $2000

### High (высокие)

- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Утечка IP при использовании Tor/VPN
- Обход Kill Switch

**Награда:** $100 - $500

### Medium (средние)

- Информационные утечки (User-Agent, fingerprint)
- CSRF в настройках
- Отказ в обслуживании (DoS)

**Награда:** $50 - $100

### Low (низкие)

- Косметические баги
- Незначительные проблемы UX

**Награда:** Благодарность

## Процесс обработки

```
1. Получение отчёта (0-24 часа)
2. Подтверждение (1-3 дня)
3. Исправление (1-7 дней для Critical)
4. Релиз исправления
5. Публикация CVE (если применимо)
6. Выплата награды
```

## Что НЕ является уязвимостью

- Использование стандартных API браузера
- Проблемы с第三方 расширениями
- Социальная инженерия
- Физический доступ к устройству
