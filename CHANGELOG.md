## Формат тегов

- `Security` — исправления безопасности
- `Added` — новые функции
- `Changed` — изменения в существующем функционале
- `Deprecated` — функции, которые будут удалены
- `Removed` — удалённые функции
- `Fixed` — исправления багов

## Версионирование

Используется [Semantic Versioning](https://semver.org/):

```
MAJOR.MINOR.PATCH

MAJOR — крупные изменения (ломающая совместимость)
MINOR — новые функции (обратно совместимо)
PATCH — исправления багов
```

Пример: `2.1.4`
- `2` — вторая мажорная версия
- `1` — первое минорное обновление в ветке 2.x
- `4` — четвёртый патч
